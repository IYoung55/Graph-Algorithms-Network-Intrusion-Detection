# GitHub submission checklist

1. Create a GitHub repository named `graph-intrusion-detection` (public or private as advisor requires).
2. Open a terminal in the extracted project directory and run:
   ```bash
   git init
   git add .
   git commit -m "Milestone 1: graph IDS prototype v0.1.0"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/graph-intrusion-detection.git
   git push -u origin main
   ```
   Replace `YOUR_USERNAME`. Authenticate with GitHub when prompted.
3. In GitHub, select **Releases → Draft a new release**, tag `v0.1.0`, attach the downloadable milestone ZIP, and publish.
4. Capture a screenshot of your successful push in the terminal **or** the repository commit history / published release.
5. Create a GitHub Project board (or use Trello), with Milestone 1 tasks and statuses. Copy its URL.
6. Share the repository/release with your advisor for review.
7. Submit the build version, direct release asset URL, project-board URL, screenshot, and screencast link in the LMS.

**Do not claim a push, release, board, or advisor review until you actually complete it.**
